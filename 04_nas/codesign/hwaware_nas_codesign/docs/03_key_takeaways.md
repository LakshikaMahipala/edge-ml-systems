# Key takeaways 

1) Hardware-aware ML is multi-objective; Pareto is the correct language.
2) Latency prediction is essential for NAS scale; ranking metrics matter most.
3) Simple baselines (graph→vector MLP, pairwise ranker) are required before GNN.
4) Co-design must search architecture and hardware knobs jointly.
5) Proxy loops are valuable to build workflow, but must be calibrated with measurement later.
